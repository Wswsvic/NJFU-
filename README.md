用于南京林业大学预约图书馆自习座位的系统。
因为需要实现非校园网访问校园网服务，所以需要借助学校提供的webvpn服务。因此导致了使用纯request的自动化脚本会被无限重定向，被限制访问资源，无法访问到目标资源。
所以采用的是模拟浏览器的方式进行登录、预约。
说明：开源是为了学习，如违反校园规定与作者无关。
此系统核心部件有web   src   inform   data   config部分，因数据量不大，所以没有采用数据库存储。运行此系统可以批量为用户预约座位。
data文件夹下是空的，部署需要自己创建三个json文件：logs.json  plans.json  users.json
如果是个人使用的话，可以只选择scripts/reserve_v8.py文件，挂载到服务器上做个定时启动，修改信息即可。
get_api下所有文件都是njfu本部图书馆的楼层与座位信息，希望能帮助到你。
