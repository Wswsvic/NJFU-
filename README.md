# 🎓 南京林业大学图书馆座位自动预约系统 (NJFU Seat Reserve System)

> **免责声明**：本项目仅供编程学习与技术交流使用。请合理使用学校公共资源，若因滥用本项目导致违反各项校园规定或造成任何不良后果，均与作者无关。

## 📖 项目描述
这是一个专为**南京林业大学**学子开发的图书馆自习座位自动化预约系统。
支持多用户注册管理、可视化的 Web 控制台、可按多种预设规则（每天、单次、特定星期等）提前一天（T-1）自动执行抢座任务，并且支持通过 PushPlus 推送抢座结果到微信。

### 💡 核心技术背景：为什么不用纯 Requests？
由于校外（非校园网环境）访问图书馆服务需要借助学校提供的 WebVPN 服务，如果使用传统的纯 Request 发包模式，会遇到严格的网关校验、导致无限重定向或资源访问受限。
因此，本项目**底层采用模拟浏览器（Headless Browser）方案**真实模拟用户的登录与选座操作，完美突破了各类风控限制。

## 🏗️ 系统架构与核心模块

本系统采用轻量级架构，无需繁重的外部数据库依赖（纯 JSON 存储），主要包含以下核心部件：
- **`web/`**：基于 FastAPI 构建的可视化前端与接口服务，负责用户控制台交互。
- **`src/`**：核心执行部件（Bot），封装了各类自动化浏览器控制、页面解析以及预约核心算法。
- **`inform/`**：消息通知模块，主要用于执行结果的微信推送（PushPlus）。
- **`data/`**：轻量级数据存储层，使用文件结构存储用户与计划。
- **`config/`**：全局环境变量与加密配置（对用户密码进行对称加密保存，保障安全）。
- **`get_API/`**：静态数据快照，包含了本部图书馆详细的楼层与所有座位的映射清单。

## 🚀 部署与使用指南

### 方式一：完整 Web 系统（推荐）
系统支持多用户自动化并发任务，极其适合部署在长期运行的云服务器上。推荐使用 **Docker** 进行一键部署：
1. 准备数据文件空壳（如未自动生成）：在项目目录创建空的 `data/logs.json`、`data/plans.json`、`data/users.json`。
2. 配合 `deploy/docker-compose.yml` 运行 `docker-compose up -d --build` 即可一键启动包含所有无头浏览器所需依赖的 Web 服务。

### 方式二：极简个人脚本
如果您只需要在自己的电脑或者个人的 Linux 机器上供**单人使用**，不想大动干戈部署 Web 界面：
您可以直接编辑并使用 `scripts/reserve_v8.py` 独立文件。只需在代码中填入您的账号与座位信息，并使用系统自带的定时任务工具（如 Crontab 或 Windows 任务计划程序）每天定时触发即可。
